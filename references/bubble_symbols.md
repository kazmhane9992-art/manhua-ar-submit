# رموز الفقاعات (Bubble Symbols)

اتباع رموز الفقاعات يُسهّل عمل المحررين، فهي رموز تُوضع قبل كل جملة لبيان نوع الفقاعة التي سيُدرج فيها النص،
وذلك يساعد على اختيار الخط المناسب وتنظيم العمل بسرعة ودقّة.

الرموز المعتمدة:

## 🔹 الكلام العادي
يُكتب **بدون أي رمز**. يُستخدم في الحوارات الطبيعية بين الشخصيات.

## 🔹 فقاعة التفكير
يُكتب بين أقواس دائرية `( )`. للأفكار الداخلية أو الحديث الذاتي.
مثال:
```
(هل يمكن أن يكون هذا صحيحًا؟)
```

## 🔹 الكلام داخل مربعات
يُكتب بين أقواس مربعة `[ ]`. للسرد أو الملاحظات الخارجية غير المنطوقة.
مثال:
```
[بعد مرور ثلاثة أيام...]
```

## 🔹 الصراخ أو الانفعال
يُسبق الرمز بـ `::`. عندما تكون نبرة الصوت مرتفعة أو غاضبة.
مثال:
```
::توقف حالًا!!
```

## 🔹 فقاعتان متلاصقتان
يُوضع الرمز `//` بجانب الفقاعة الثانية فقط، بينما تُعامل الفقاعة الأولى بالرمز المناسب لها.
يدل على أن الفقاعتين متصلتان في الحوار.
مثال:
```
هذا مستحيل!
لا، بل هو حقيقي //
```

## 🔹 ملاحظة من المترجم
يُسبق الرمز بـ `م/` أو كلمة "مترجم". لإضافة توضيحات قصيرة موجهة للقراء.
مثال:
```
م/ الاسم يعني "العاصفة السوداء" باليابانية.
```

## 🔹 كلام داخل الصورة أو خارجها
يُسبق الرمز بـ `#`. للنصوص المدمجة في الصورة أو الموضوعة خارج الإطارات.
مثال:
```
#لافتة على الجدار: "ممنوع الدخول"
```

## 🔹 فقاعات النظام
يُسبق الرمز بـ `$`. لرسائل النظام أو الواجهات الرقمية.
مثال:
```
$تم حفظ التقدم بنجاح.
```

## 🔹 كلام فوق أو بجانب رؤوس الشخصيات
يُسبق الرمز بـ `@`. للنصوص المصاحبة التي تظهر قريبة من الشخصيات.
مثال:
```
@يتنهد بعمق...
```

## 💡 ملاحظات مهمة

- لا تغيّر الرموز أو ترتيبها إلا بتنسيق مسبق مع الفريق.
- استخدمها باستمرار لتوحيد أسلوب العمل بين المترجمين والمحررين.
- الهدف من هذه الرموز هو الوضوح، السرعة، والتنسيق المنهجي في كل فصل.
